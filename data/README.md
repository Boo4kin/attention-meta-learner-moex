# Данные

## Si_1min_2025-05-02_2026-04-30.csv

Исходная выборка из 219 529 минутных баров фьючерса Si (USD/RUB), 02.05.2025–30.04.2026.

Разделитель — точка с запятой. Поля:

| Поле | Значение |
|---|---|
| TICKER | код инструмента |
| PER | период бара в минутах |
| DATE, TIME | дата и время |
| OPEN, HIGH, LOW, CLOSE | OHLC-цены |
| VOL | объём |
| OPENINT | открытый интерес |

## backtest_results.csv

Экспорт holdout-бэктеста из исследовательского ноутбука: 7 550 строк за период 19.02.2026–30.04.2026. Содержит цены, сигналы, PnL, кривые капитала и динамические веса Attention Meta-Learner.

Данные и результаты предназначены для воспроизведения учебного исследования. Они не являются торговыми сигналами или инвестиционной рекомендацией.
